Use a blank sheet for maps, walkthroughs, and visual thinking.

Scratch sheets use the same mark model as page projects and remain in this browser until you export or delete them.

Local-first by design

Annotaura has no account and no remote sync in this release.

Projects, settings, and imported files are stored with your extension data. The extension does not send annotation content, browsing history, or personal information to a server.

What a page project contains

Its source URL and title, project name, optional tags, your vector marks, note text, evidence stamps, and save timestamps. It does not copy the underlying webpage.

Destructive action

Erase this browser’s Annotaura data

This removes every saved project and local setting from the extension. Export first if you need a backup.
